# Strategy

The agent is a growth operating system, not a rank-report generator. Its causal
chain is **search demand → website behaviour → website change → site lead →
Bitrix24 qualification → deal → revenue**. It ranks work by expected incremental
qualified leads, evidence confidence, effort and time to impact.

The initial 13-week target is a provisional 30% increase in qualified site leads.
After 14 days of validated baseline data, the target must be recalculated rather
than treated as a promise. No visibility, content or CRO task is selected without
a credible connection to the North Star.
